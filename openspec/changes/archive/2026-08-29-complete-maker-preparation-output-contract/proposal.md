## Why

The v0.2.50 preparation product plus PR #155 supplies the two bounded file jobs
and hardened OKX reconstruction, but Fiet Maker still lacks one coherent
current-policy output chain, complete source-qualification evidence, and
schema-identified exact exports. The follow-up must close that producer
boundary without weakening the existing file-job safety contract or creating a
second diagnostic or legacy execution path. The implementation checkpoint at
`3481f4e386c349af748684b87f9b2a50695141fe` also revealed that repository-only
qualification tooling had begun to absorb Maker-owned Candidate A/C,
scheduler, descriptor, and two-pair orchestration semantics. Those semantics
must return to Maker before release identity is frozen; otherwise CEX Broker
would become a thesis coordinator rather than a reusable market-data producer.

## What Changes

- **BREAKING** Make capability policy v3 and resource policy v2 the only accepted live preparation tuple; reject mixed or previous pins before I/O and remove runtime dispatch and conformance behavior for prior versions.
- Retain historical receipts unchanged as audit evidence, but require a new append-only current-policy qualification receipt before any vendor bundle can support a current `already_covered` or `promoted` result.
- Require the request, result, promotion receipt, conformance evidence, and published product pin to carry one coherent set of current capability, resource, adapter, and acquisition identities.
- Align the normative OKX path with PR #155: record sequence gaps, remain unanchored until a later complete snapshot, scan the full required clock, and fail only the required targets that were not validly re-anchored.
- Add published, bounded, secret-free forensic-ledger and qualification-record schemas observed from that same reconstruction path, including sequence, unanchored, stale, future-state, checksum-conflict, and inactive-market evidence.
- Preserve the atomic backfill result as the runtime commit marker and freeze the detailed subcodes, Maker-consumed diagnostic keys, and six lag buckets already emitted by PR #155.
- **BREAKING** Version the canonical export result contract so each levels and summary descriptor binds its relative path, SHA-256, byte length, row count, and canonical schema identity.
- Validate each Parquet file against an ordered capture-core physical projection and return `archive_data_invalid/parquet_projection_schema_mismatch` before committing a mismatched success.
- Preserve existing caller-owned attempt-directory, no-follow, byte-cap, atomic-result, exporter read-only, and `cex-broker` bin-compatibility requirements.
- Expose source-complete, policy-neutral tape preparation as a CEX-owned package-library operation that Maker can invoke from its local preparation shim or sidecar without a CEX repository checkout. Preserve exactly two standalone executables and the twelve-schema package; the operation returns existing CEX qualification and exporter evidence rather than a Maker-specific aggregate document.
- Make every CEX preparation and qualification attempt pair-local and required-clock-role-neutral. CEX validates exact request, target membership, source evidence, archive, and export identities, but MUST NOT interpret Candidate A/B/C roles, Maker scheduler/configuration fingerprints, DEX inputs, target-to-policy-invocation mappings, or `reference_depth_stale` outcomes.
- Assign the one operator-facing workflow, Candidate A/B/C construction, untruncated capacity preflight, admitted-clock derivation, Maker-owned derivation descriptor, and atomic ARB-USDT/ARB-USDC verdict to Fiet Maker.
- Publish all twelve current schemas, both executables, policies, conformance evidence, and one immutable successor product pin derived from the actual registry artifact.
- Require pair-scoped `fill_gaps`, depth-100 qualification, selection, and export for OKX Spot ARB-USDT and ARB-USDC over one common 20-to-30-complete-UTC-day window under the unchanged 5,000 ms prior-as-of bound.
- Resolve the accepted pre-freeze blockers before version reservation: true four-state reconstructor yielding, authoritative required-clock partition validation, record/interval causality, pair-local durable verdicts, exact input binding, and semantic tape/archive digest and seam verification. Maker-descriptor semantic validation and two-pair aggregation are removed from the CEX blocker set because they are Maker-owned.
- Add an explicit RED/GREEN test event for any reported branch-suite failure and require the repository-declared unit suite plus build, type, package, conformance, ClickHouse, image-smoke, and secret-reflection checks to pass.

## Capabilities

### New Capabilities

- `market-data-source-forensics`: Defines bounded qualification evidence emitted from the same reconstruction path for sequence, anchoring, provider-object, and required-clock failures.

### Modified Capabilities

- `cex-market-data-preparation-executables`: Versions the existing exporter result and product pin, preserves the bounded file-job boundary, and adds schema-identified export and release-acceptance requirements.
- `market-data-vendor-backfill`: Replaces live legacy-policy acceptance with one capability-v3/resource-v2 path and requires coherent current identities and Maker-consumable pair-scoped outputs.
- `cex-order-book-replay-archive`: Defines the ordered capture-core physical projections, validates Parquet schemas, and preserves exact selection and receipt lineage.
- `cex-broker-service-architecture`: Preserves backfill write-through-forwarder and exporter read-only boundaries while removing Fiet TEE from executable, build, release, and provenance ownership.

## Impact

- Affects the vendor-backfill request decoder, policy registry, domain result/receipt construction, OKX reconstruction diagnostics, exact-selection exporter, file-job commands, package build, release-evidence generation, and conformance fixtures.
- Affects the qualification package-library boundary and removes Maker-specific Candidate, descriptor, capacity, and aggregate-pair decisions from CEX repository-only orchestration.
- Changes the canonical exporter result schema and dependent schema-manifest/product-pin identities; Maker must update its pinned schema copy and consumer validation for the published successor.
- Removes live compatibility with capability policies v1/v2 and resource policy v1. Historical archive evidence remains auditable but cannot authorize a current vendor selection until it is requalified under the exact current tuple.
- Requires coordinated CEX release qualification and Maker pin/consumer verification. Maker owns the preparation state machine, Candidate roles, strategy, final four-member artifact, real-loader proof, and two-pair atomic commit; CEX owns provider acquisition, source reconstruction and forensics, forwarder-mediated archive mutation, pair-local clock qualification, selection, and export.
